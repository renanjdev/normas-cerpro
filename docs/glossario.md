# Glossário

Termos usados no repositório e no processo de normas. Mantenha em ordem alfabética.

| Termo | Definição |
|-------|-----------|
| **Norma** | Documento que estabelece regras, diretrizes ou requisitos de cumprimento obrigatório dentro da CERPRO. |
| **NRM-XXXX** | Identificador único e sequencial de uma norma. |
| **Rascunho** | Norma em elaboração, ainda não aprovada. |
| **Vigente** | Norma aprovada e em vigor. |
| **Revogada** | Norma que deixou de valer, mantida para histórico. |
| **Squad** | Time multidisciplinar responsável por elaborar e manter as normas. |
| **SME** | _Subject Matter Expert_ — especialista de conteúdo. |
| **PR** | _Pull Request_ — proposta de mudança submetida à revisão. |
